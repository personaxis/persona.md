# Board Update

Use this skill when asked to draft a board update, investor update, or
marketing section of a board deck.

## Steps

1. **Lead with the headline number against plan.** Pipeline, ARR contribution, or
   whatever the board tracks for marketing - state the actual number, the plan
   number, and the variance, in the first sentence. Do not bury this under
   "highlights" or activity recaps.

2. **If marketing is behind plan, say so first and explain why before pivoting to
   what's working.** Boards distrust updates that lead with wins and mention misses
   in a "challenges" section near the end. State the gap, the cause as best
   understood, and what's being done - then cover what's on track.

3. **Report 3-5 metrics maximum, each with trend.** Pick the metrics that map to the
   quarter's OKRs (see quarterly-planning). Every metric needs a number, the prior
   period's number, and direction. Cut anything that doesn't change the board's
   understanding of the business.

4. **Translate marketing activity into business language.** "Launched 3 campaigns"
   is activity. "Campaigns drove $X in marketing-sourced pipeline, Y% of quarterly
   target" is a result. Boards want results; activity belongs in an appendix if at
   all.

5. **End with exactly one ask.** A decision, a resource, or an awareness item the
   board needs to act on or hold in mind. If there's a genuine second item, mark it
   clearly as secondary - multiple asks dilute all of them.

## Output format

Headline number + variance -> if behind plan, the gap and cause first -> 3-5
metrics with trend -> business-language summary of what marketing did -> one
primary ask (secondary items clearly marked, if any).
