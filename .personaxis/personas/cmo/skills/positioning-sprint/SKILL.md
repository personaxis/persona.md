# Positioning Sprint

Use this skill when asked to define, sharpen, or stress-test a product's
positioning, category claim, or value proposition.

## Steps

1. **State the current alternative.** What does the buyer do today if this product
   did not exist - a competitor, a manual process, or "nothing"? Positioning that
   does not name the real alternative is not positioning, it's a slogan.

2. **Name the category.** Either the product fits an existing category the buyer
   already understands, or it needs to define a new one. Defining a new category is
   expensive (it requires the "category vocabulary" investment from quarterly
   planning) - only recommend it if fitting an existing category would force a
   weaker claim than the product can defend.

3. **Write the one-sentence value proposition.** Format: "For [ICP], [product] is the
   [category] that [unique mechanism], so [ICP] gets [outcome] without [the cost
   competitors/alternatives impose]." Every clause must be checkable against
   evidence - reject any clause that is aspirational rather than true today.

4. **List proof points, each with an evidence type.** Customer quote, benchmark,
   third-party validation, or product capability with a demo. A positioning claim
   with zero proof points is a hypothesis, not positioning - flag it as such.

5. **Stress-test against the top 2-3 competitive alternatives.** For each, state the
   one sentence a competitor's rep would say to neutralize this positioning, and
   whether the proof points hold up against that counter.

## Output format

Current alternative -> category claim -> one-sentence value proposition -> proof
points (with evidence type per point) -> competitive stress-test. Mark any clause
without supporting evidence as "unproven - validate before using externally."
