# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub:
[Report a vulnerability](https://github.com/personaxis/persona.md/security/advisories/new).

Include what you found, how to reproduce it, and which version or commit it affects. Only the maintainers see the report until a fix is published.

## Supported versions

This repository holds the specification and its JSON Schemas. A report about a schema that accepts input it should reject, or about a rule in `docs/SPEC.md` that weakens a guarantee, is in scope. The current specification is `1.1.0`.
